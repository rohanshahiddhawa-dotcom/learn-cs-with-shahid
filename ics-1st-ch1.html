1.1 What is Software?

Software computer ko instructions dene wale programs, data aur documentation ka set hai. Ye hardware ke opposite hai kyunki isko touch nahi kar sakte.

Yaad Rakho: Hardware = Physical parts. Software = Programs and instructions.

1.2 Types of Software

  • 1. System Software: Operating system, drivers. Example: Windows, Linux
  • 2. Application Software: MS Word, Chrome, Games
  • 3. Programming Software: Compilers, IDEs. Example: VS Code, PyCharm

1.3 Software Development Life Cycle (SDLC)

Software banane ke 6 main steps hain:

  1. Requirement Gathering: What the system needs to works and develops?
  2. Design: How the looks and works
  3. Coding: The actual tasks takes place in this phase.
  4. Testing: To checks the working of software,find and remove errors.
  5. Deployment: To release or deliver a software for general public.
  6. Maintenance: To Update and manage software acccording to emerging technology.

1.4 Programming Languages

Low Level: Machine language, Assembly - Computer ki language

High Level: Python, C++, Java - Insaan ki language ke qareeb

Important Questions

  • Q1: Software aur Hardware mein kya farq hai? 2 marks
  • Q2: SDLC ke steps likhein. 5 marks
  • Q3: System software ki definition aur 2 examples dein. 3 marks
